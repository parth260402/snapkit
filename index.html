Privacy Policy for SnapKit

Effective Date: November 14, 2026 | Application: SnapKit (Offline Image & PDF Toolkit)
Privacy Guarantee: SnapKit operates 100% locally on your device. We do not collect, transmit, store, or sell your documents, photos, or personal data. No accounts, no ads, no trackers.

1. Overview

SnapKit is developed as a fully offline utility application. The application does not maintain external database servers, APIs, or cloud synchronization services. All tasks—including image compression, cropping, format conversion, passport photo generation, and PDF manipulation—execute entirely within your device's local memory and sandbox storage.

2. Information Collection and Transmission

We believe in absolute data minimization:

  • No Personal Identification Data: SnapKit does not require or collect your name, email address, phone number, device identifiers, or IP address.
  • No Document or Media Uploads: Selected photos and PDF documents are never uploaded to any remote server or third-party service.
  • No Analytics or Tracking SDKs: SnapKit does not integrate Firebase, Google Analytics, telemetry software, crash trackers, or behavioral profiling tools.
  • No Advertisements: The application contains no advertising SDKs or third-party marketing frameworks.

3. Device Storage & Permission Model

SnapKit strictly respects Android's modern privacy standards:

  • User-Controlled File Selection: SnapKit accesses images only when explicitly chosen via the system Android Photo Picker, and documents via the system Storage Access Framework (SAF).
  • Temporary File Handling: Temporary files produced during processing tasks (e.g., intermediate PDF rendering or image caching) reside solely in the app-private internal cache and are cleared automatically or upon user request.
  • Export Destinations: Final exported files are written only to directories chosen explicitly by the user using the system file save dialog.

4. Third-Party Libraries and Network Access

All dependencies utilized within SnapKit are vetted open-source libraries focused exclusively on on-device image decoding, image transformation, and PDF document generation. The application does not communicate with external servers.

5. Children's Privacy

SnapKit does not collect any data from any users, including children under the age of 13. It is safe for general use across all age groups.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect future version updates. Any modifications will be documented on this page with an updated effective date.
